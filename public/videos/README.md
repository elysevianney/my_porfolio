# Matière — ressources originales

`matiere-loop.mp4` est une sculpture abstraite créée spécifiquement pour ce portfolio avec le shader de `scripts/matiere-scene.html`. Aucun extrait de vidéo, modèle 3D tiers ou portfolio existant n’a servi de source visuelle.

Le volume est défini par une surface implicite en anneau à trois lobes. Les oscillations utilisent des fréquences entières sur un cycle de 12 secondes pour obtenir une boucle continue. Un éclairage de studio et une ombre douce lui donnent un aspect sculptural.

- H.264, 768 × 768, 20 images/s, sans audio, environ 175 Ko.
- Affiche JPEG d’environ 24 Ko pour le pré-rendu et la réduction des mouvements.
- Sources et générateur conservés dans `scripts/`, hors des ressources publiques de l’application.

Régénération : voir le README à la racine du dépôt.
