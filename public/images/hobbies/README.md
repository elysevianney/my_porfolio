# Illustrations des loisirs

Six illustrations SVG originales créées pour ce portfolio, sans ressource externe.
Palette bordeaux et rose poudré, canevas 960 × 720 (4:3).

Le contenu est défini dans `src/app/data/hobbies.data.ts` et le modèle dans
`src/app/models/hobby.model.ts`. Pour utiliser une photo, déposer le fichier ici,
puis modifier `image` et `imageAlt` dans le dataset. Format conseillé : WebP ou
JPEG, 960 × 720 px. Les images sont recadrées au centre avec `object-fit: cover`.

La section est assemblée avant Contact dans `src/app/app.html`.
